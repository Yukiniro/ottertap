# 播放时自动静音其他

设置页「Playback」有一项 `Mute other tabs when this starts playing`，默认关闭。关闭时和现在一样：别的标签不会因为这里开始播放而被静音。

打开后，只在当前活动标签、并且是小獭当时正在控制的那一条媒体上生效。它必须是从暂停或结束转为播放，而且能归到下面两种之一：

- 小獭自己的播放控制（弹出面板、浮动药丸、页内播放键或扩展命令发出的播放）。
- 用户直接在这一条媒体上按下主指针，或按下空格、Enter、MediaPlayPause。

网页自己调用 `play()`、站点自己的播放按钮、自动连播下一条、后台页、只是切换标签或打开面板、已经在播、轮询，都不会。分不清是谁让它播放时，不静音。

被静音的名单和「静音其他」相同：当时正在出声、且不是当前标签的那些。当前标签的浏览器静音、媒体播放状态和音量不动。成功的一批写进 `ottertap-mute-batch-v1`，用原来的 `Undo mute others` 撤销。没有目标，或一个都没静音成功时，不报错，也不假装成功，也不换掉上一批。

每次自动成功，以及每次撤销，都会在这次浏览器会话里拦住下一次自动静音 5 秒。到点就可以。这 5 秒不是设置，也不进导出。手动的静音其他、只听当前和撤销不受它限制。连续的播放事件和多个 frame 不会记成两批。

自动成功时页面上出现 `Muted other tabs`，与起冷却是同一个条件，所以 5 秒内最多一条。自动失败不起冷却，失败说明按同样的 5 秒去重。见 [quiet-feedback.md](quiet-feedback.md)。

冷却放在 `chrome.storage.session` 的 `ottertap-auto-mute-v1`。关掉浏览器就没了。

## Sub-features

- 默认关。设置、旧备份和坏值都是关。八种界面语言都有这一项。
- 用户让当前媒体开始播放。小獭的播放，或在该媒体上的播放操作，静音其他正在出声的标签。
- 不触发。网页连播或 `play()`、后台页、已经在播、切标签、开面板、站点按钮，都不静音。
- 5 秒。成功后 5 秒内不重复；到点可以。
- 撤销冷却。撤销后再过 5 秒才允许自动重静音。手动静音其他在这 5 秒里仍然可用。
- 多个 frame。只有小獭正在控制的那一条会触发，并且只记一批。
- 导入导出。导出带上开关。旧备份没有这个键时保持关闭，其他字段还在。

## How to get to it (user POV)

1. 另一个标签正在出声。
2. 设置里打开「当前媒体开始播放时自动静音其他标签」。
3. 回到当前页，用小獭或这一条媒体自己的播放，让它从暂停开始播。
4. 其他正在出声的标签被浏览器静音。当前页的音量不变。
5. 误触时点撤销。5 秒内它不会马上再静音那些标签。

## Driving it with Playwright

```bash
node .cursor/skills/verify-ottertap/scripts/session.mjs drive auto-mute-others
```

它会改 profile，退出前把开关关回，并取消音乐标签的浏览器静音。夹具是 `/tone-music`、`/video`、`/player`（站点按钮）、`/frames`（顶层视频加 `/frame-child`）。后台看标签是不是活动标签，不看 `document.visibilityState`。浏览器里已经有一个聚焦窗口时，只认那个窗口的活动标签；一个窗口都没有聚焦时，活动标签仍算当前。

## Gotchas

- 点在站点按钮上、或任何不是这一条媒体元素的地方，再由脚本调用 `play()`，都不算。自定义播放器若自己画按钮，需要用户用小獭的播放，或点到视频元素本身。
- 播放事件晚于手势或小獭播放命令超过 1 秒，也不算。
- 5 秒用 `Date.now()`。到点的那一刻允许下一次自动静音。
- 空名单或全部失败不写入冷却，也不替换已有批次。
