# OtterTap 功能地图

验证主界面是扩展本身。索引里的每一条都要能从用户路径走到可观察的结束状态。`scripts/session.mjs` 目前脚本化了弹出面板播放、滚轮音量、快进快退步长、快进快退随倍速放大、音量调节步长、低音量滚轮细步长、Shift 粗调步长、倍速增减步长、扩展命令画中画、全局默认倍速、按住临时加速、同键短按跳长按加速、逐帧、页内快捷键改键、浮动药丸倍速、浮动药丸播放跳转、浮动入口旁注、从音量药丸打开弹出面板、仅在播放时显示浮动入口和滚轮方向。仅全屏时悬停滚轮、侧栏聊天和文档大纲忽略，以及记住站点、网站规则和不显示浮动站点这三份名单的本地过滤，三处名单各自的「当前站」，和记住站点的「清空全部」，以及水平镜像、进度标记、一键静音其他发声标签，撤销最近一次静音其他，只听当前，当前媒体开始播放时自动静音其他标签，和镜像与标记的快捷键也已脚本化。镜像与标记的页内提示也已脚本化。播放中自动跟随当前媒体也已脚本化。选中换到另一条时的短暂轮廓也已脚本化。上一条和下一条媒体也已脚本化。弹出面板的媒体列表也已脚本化。音量药丸里的上一条和下一条也已脚本化。音量药丸里的画中画也已脚本化。页内画中画快捷键也已脚本化。进出画中画的页内提示也已脚本化。画中画中的面板与浮动状态也已脚本化。切走标签后扩展命令仍控画中画媒体也已脚本化。不自动画中画的站点也已脚本化。自动进出画中画的页内提示和失败冷却也已脚本化。接着看的进度保存也已脚本化。弹出面板的睡眠定时也已脚本化。睡眠进行中的取消和再续 15 分钟也已脚本化。睡眠定时的开始、取消、到期和临近页内提示也已脚本化。弹出面板按当前倍速折算的本集剩余也已脚本化。睡眠定时的快捷键与扩展命令也已脚本化。睡眠进行中浮动入口旁注的倒计时也已脚本化。其余条目的选择器和断言已经写在各自文件里，用同一次 `launch` 的 Chromium（或 `pnpm e2e` 里点名的那条测试）来驱动。一条失败就报告失败原因，写进该文件的 Gotchas，不要把旅程改容易。

新增功能文件、写旅程之前，先读 `../SKILL.md` 的「写旅程前的四条硬规则」：涉及页面可见性、切走标签、切走自动进画中画的检查，必须另起 Chromium 并用 `connectOverCDP({ noDefaults: true })` 连，不能用会话默认的 Playwright（页面永远 `visible`）；新增相邻设置键或改名存储键前，先把旅程和 e2e 里宽泛的存储正则断言（如 `/sleep/i`）收窄成精确键名或允许名单；happy-dom 断言 DOM 只用 `assert.ok` 或对标量 `strictEqual`，禁止对节点 `assert.equal` / deep equal；设置页名单空态必须 scope 到容器（如 `#floating`），禁止裸 `getByText('No sites yet.')`。

跑 `pnpm e2e` 之前总是先 `pnpm build`、`pnpm verify-build`、`pnpm site:build`，与 `.github/workflows/ci.yml` 相同。不要假设 `site/out` 已在。只开验证会话时不必构建官网。
