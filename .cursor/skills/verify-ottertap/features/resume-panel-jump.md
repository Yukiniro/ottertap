# 接着看：面板跳转与清除

弹出面板的进度行里，当前媒体有接着看进度时出现两个小按钮：「跳到接着看」（带时刻的提示文字）和「清除接着看」。没有进度时不占位。跳转成功出现和自动跳回相同的页内提示。与「跳到标记」（本页的进度标记）是两个入口，文案分开。

## Sub-features

- 出现条件。后台为弹出面板的读取附带账本里的进度；没有进度、排除站点或站内浮动入口（不读账本）时不出现。
- 跳到接着看。按钮 `aria-label`「跳到接着看」，`title` 附目标时刻。点击走媒体命令 `{ type: 'resume', action: 'jump' }`，控制器现读账本取最新值，落到 `time - 3` 秒；即使页面已在更后面也照跳（手动跳不判断「附近」）。媒体不能跳转时禁用。
- 清除接着看。删当前媒体这一条；没有进度时按钮同样不占位。排除的媒体两个按钮都不出现，删除走设置页的进度列表。
- 文案区分。与「跳到标记」「清除标记」不同的键（`jumpToResume` / `clearResume`），不会混淆两种记忆。
- 进度标记不受影响，仍只留在页面里。

## How to get to it (user POV)

1. 存下进度后打开弹出面板。进度行里出现历史图标按钮，悬停显示「跳到接着看 · mm:ss」。
2. 点它：视频跳过去，页面顶部短暂显示「从 xx:xx 继续」，按钮随新读取消失（那条已清或仍在都按最新状态显示）。
3. 点清除按钮：两个按钮都收起，重开页面也不再自动跳。

## Driving it with Playwright

复用 `drive resume-save` 的 Lecture 夹具，存进度后在弹出面板里找 `button[aria-label="跳到接着看"]`，断言 `title` 是 `跳到接着看 · mm:ss`、禁用态与 `seekable` 一致；点击后 `#media` 的 `currentTime` 落在减三秒处并出现提示字样。

按钮出现条件、禁用态、命令发送与消失由 `tests/resume-panel.test.ts` 锁住；命令在控制器和后台的行为由 `tests/resume-jump.test.ts` 锁住。

## Gotchas

- 只有弹出面板读账本；页内浮动面板不显示这两个按钮（省一次存储读取，浮动也不需要）。
- 跳转读的是点击那一刻的账本，不是面板打开时的快照。
- 直播、不可 seek 的媒体即使有残留进度也只禁用跳转，不隐藏清除。
