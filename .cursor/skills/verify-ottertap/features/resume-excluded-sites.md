# 接着看：按站点排除

设置页「接着看」里的名单「不在这些站接着看」。加进去的域名及其子域名不再写新进度，也不再自动跳回；以前留下的记录还在，能在进度列表里看到和删除。与网站规则、不显示浮动按钮的站点两个名单互不影响，进设置导出。

## Sub-features

- 添加与移除。输入域名或网址，按主机名规范化（小写、去路径）；重复会提示。名单按域名含子域名匹配，`youtube.com` 也盖住 `www.youtube.com`。
- 不写。排除站的播放不再写新进度，已有条目停在最后一次更新。
- 不跳、不显示。排除站重开页面不自动跳回；弹出面板也不显示「跳到接着看」和「清除接着看」。面板里的「清除接着看」仍可用，方便把旧记录清掉。
- 与其他名单独立。停用站点（网站规则）本来就不记；这个名单管的是「站点正常启用，但不想接着看」。
- 导出导入。名单是设置的一部分，随备份走；旧版本备份导入后名单为空。

## How to get to it (user POV)

1. 弹出面板右上角打开设置，左侧导航点「接着看」。
2. 在「不在这些站接着看」输入 `youtube.com` 回车；列表出现这一行，旁边有移除按钮。
3. 到该站播放长视频：不记进度、重开不跳；回设置点移除后恢复。

## Driving it with Playwright

复用 `drive resume-save` 的 Lecture 夹具（`https://lecture.ottertap.test`）。

1. 存一条进度后，设置页 `#resume` 里向 `#resume-excluded-domain` `fill` `lecture.ottertap.test` 并提交。
2. 重开 `/watch?v=1`：`currentTime` 停在 0 附近，账本里那条的 `savedAt` 不变。
3. 弹出面板不出现「跳到接着看」；账本列表（设置页「接着看进度」）仍能看到这一条。
4. 移除名单行后重开：恢复自动跳回。

域名规范化、子域名匹配、并发合并（另一页加的与本页删的都算数）和备份往返由 `tests/resume-settings.test.ts` 锁住；排除站不写、面板不显示由 `tests/resume-jump.test.ts` 的后台测试锁住。

## Gotchas

- 名单认的是放媒体的页面域名（iframe 里就是 iframe 的域名），不是视频文件的 CDN 域名。
- 排除不删旧记录；想清掉用进度列表的删单条或清空。
